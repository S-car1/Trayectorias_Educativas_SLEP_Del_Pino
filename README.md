# Trayectorias educativas SLEP Del Pino

Visor interactivo de la trayectoria hacia la educación superior de estudiantes que cursaron enseñanza media en establecimientos del SLEP Del Pino.
Es un solo archivo (`index.html`) con los datos incrustados. Datos públicos de MINEDUC (Matrícula por estudiante) y SIES; sin RUT ni nombres.
